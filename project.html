The AI Sports Match Predictor Agent

A FastAPI-powered backend that orchestrates a 4-agent AI pipeline to analyse match history, decode opponent strategy, generate tactical recommendations, and explain coaching insights — all served through a live dashboard. Built using IBM Bob with the Groq LLM API.

Architecture

4-Agent Pipeline

Each agent receives the output of the previous one, building context progressively.

Agent 1
Match Analysis Agent
Analyses historical match data for patterns, win/loss trends and performance stats against a given opponent.
Agent 2
Opponent Strategy Agent
Decodes the opponent's tactical approach — formations observed, key weaknesses, and playing style tendencies.
Agent 3
Strategy Recommendation Agent
Uses Agent 1 & 2 outputs to suggest optimal formations, set-piece tactics, and counter-strategies.
Agent 4
Insight Explanation Agent
Converts technical recommendations into plain coaching language that managers and players can act on.

main.py — Pipeline Orchestrator

The FastAPI application wires all 4 agents together, computes dashboard statistics, and exposes the REST API.

main.py Python 
"""
FastAPI backend — AI-powered Game Strategy Advisor
Orchestrates the 4-agent pipeline and serves the dashboard.
"""
import os
from dotenv import load_dotenv

load_dotenv(override=False)
load_dotenv("config.env", override=False)

from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import FileResponse, HTMLResponse
from pydantic import BaseModel
from typing import Optional

from agents.rag import RAGRetriever
import agents.match_analysis_agent as match_agent
import agents.opponent_strategy_agent as opponent_agent
import agents.strategy_recommendation_agent as strategy_agent
import agents.insight_explanation_agent as insight_agent

app = FastAPI(title="Game Strategy Advisor", version="1.0.0")

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

retriever = RAGRetriever()  # Single shared instance, loaded once on startup

@app.post("/api/analyze")
def analyze(req: AnalysisRequest):
    """Main pipeline: run all 4 agents sequentially."""
    ma_result = match_agent.run(opponent, retriever)
    os_result = opponent_agent.run(opponent, retriever)
    sr_result = strategy_agent.run(
        opponent=opponent,
        match_analysis=ma_result["analysis"],
        opponent_analysis=os_result["analysis"],
        key_weaknesses=os_result["key_weaknesses"],
        formations_seen=os_result["formations_observed"],
    )
    ie_result = insight_agent.run(
        opponent=opponent,
        recommendation=sr_result["recommendation"],
        opponent_weaknesses=os_result["key_weaknesses"],
    )
    return {
        "match_analysis":        ma_result,
        "opponent_strategy":      os_result,
        "strategy_recommendation": sr_result,
        "coaching_insights":       ie_result,
        "dashboard_data":          dashboard_data,
    }

config.env — Model Configuration

Uses two Groq models — a lightweight prompt guard for safety and a powerful chat model for analysis.

config.env ENV 
# Groq API credentials
GROQ_API_KEY=your_groq_api_key_here

# Safety guard model (lightweight prompt injection filter)
GROQ_GUARD_MODEL=meta-llama/llama-prompt-guard-2-22m

# Primary chat / reasoning model
GROQ_CHAT_MODEL=qwen/qwen3.8-27b

start.ps1 — Startup Script

One-command launch — creates the virtual environment, installs dependencies, and starts the server.

start.ps1 PowerShell 
# AI Game Strategy Advisor — Startup Script
Write-Host "=== FC Dynamo AI Strategy Advisor ===" -ForegroundColor Cyan

# Create virtual environment if missing
if (-not (Test-Path ".venv")) {
    uv venv .venv --python 3.14
}

# Install / sync dependencies
uv pip install -r requirements.txt --python .venv\Scripts\python.exe

# Load API key from config.env if .env is not present
if (-not (Test-Path ".env")) {
    if (Test-Path "config.env") {
        Copy-Item config.env .env -Force
    }
}

# Start FastAPI server
& ".venv\Scripts\python.exe" -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload

Setup

How to Run

1
Add your Groq API key to config.env — replace your_groq_api_key_here with your actual key from console.groq.com
2
Open PowerShell in the project directory and run .\start.ps1 — it handles virtual environment creation and dependency installation automatically
3
Open your browser at http://localhost:8000 to access the live dashboard
4
Select an opponent and click Analyze — the 4-agent pipeline runs and results populate the dashboard in real time
